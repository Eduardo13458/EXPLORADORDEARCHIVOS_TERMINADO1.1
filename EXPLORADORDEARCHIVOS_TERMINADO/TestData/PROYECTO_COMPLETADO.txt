### Bug Encontrado
- **Error**: `ArgumentOutOfRangeException` en `btnDrives_Click`
- **Causa**: Variable `idxFolder = -1` cuando no encuentra archivos de imagen
- **Solución**: Agregada validación antes de acceder al índice

```csharp
// ANTES (línea 498):
imageList1.Images[idxFolder]

// DESPUÉS (línea 498):
idxFolder >= 0 ? imageList1.Images[idxFolder] : null
```
